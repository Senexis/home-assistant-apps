# Proton Mail Bridge

Runs Proton's official Bridge so Home Assistant can read Proton Mail with its IMAP integration and send
it with its SMTP integration. Bridge is downloaded from proton.me when the app is built and checked against
a pinned checksum. IMAP and SMTP are only reachable from inside Home Assistant; nothing is opened on your
network. Requires a paid Proton plan.

## Signing in

1. Open **Proton Bridge** from the app page (**Open web UI**) or from the sidebar.
2. Sign in with your Proton email and password. Bridge then asks for your two-factor code, and your mailbox
   password if your account has one.
3. Bridge starts synchronizing your mail. The first time this can take a while; new mail reaches Home
   Assistant once it has finished.
4. **Mailbox details** on the **Account** tab shows the hostname, ports, username and password to use in
   Home Assistant. The password is generated by Bridge; it isn't your Proton password and only works
   against this Bridge.

## Connecting Home Assistant

Both integrations use the same details from **Mailbox details**, with certificate verification off
(Bridge uses a self-signed certificate).

| | IMAP integration (UI) | SMTP integration (YAML, `notify:` with `platform: smtp`) |
|---|---|---|
| Server | the hostname from **Mailbox details** | `server:` the same hostname |
| Port | `9143` | `port: 9025` |
| Security | SSL. Set **IMAP connection** to **SSL** in Settings; Home Assistant's IMAP integration can't use STARTTLS. | `encryption: starttls` when **SMTP connection** is **STARTTLS** (the default), `encryption: tls` when it's **SSL** |
| Certificate verification | **Verify SSL certificate** off | `verify_ssl: false` |
| Username and password | from **Mailbox details** | `username:` and `password:` from **Mailbox details** |

For SMTP, `sender:` must be one of your Proton addresses.

## Settings

- **Show All Mail** lists the All Mail folder in the mailbox Home Assistant sees.
- **IMAP connection** and **SMTP connection** choose SSL or STARTTLS.
- **Alternative routing** reaches Proton through alternative network routes if Proton's servers are
  blocked where you are.
- **Collect usage diagnostics** sends anonymous usage statistics to Proton.
- **Check for updates** asks Proton's update server which version is current.
- **Restart**, **Repair** and **Reset** are under Maintenance. Each one asks before it starts. After a
  reset you sign in again and enter the new password in Home Assistant.

**Split addresses** (on the **Account** tab) gives each Proton address its own mailbox and login; Home
Assistant uses the first. Switching between split and combined means setting up the IMAP integration
again from scratch.

The **Console** tab is Bridge's own command line, for anything the page doesn't cover.

## Updates

Bridge's own automatic updates are off, because Bridge is updated together with this app. A daily check
in this repository publishes a new app version, after a successful test build, when Proton releases a new
Bridge or the Debian base image is refreshed. Home Assistant then offers the update; the **Changelog**
lists what changed.
